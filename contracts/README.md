# Shared Contracts Package

This package contains shared contracts consumed by backend, worker, and frontend.

## Current contents

1. Canonical extraction JSON schemas under `contracts/schemas`.
2. Schema versioning policy under `contracts/schemas/README.md`.
3. API response envelope and error contracts under `contracts/api`.

## Planned additions

1. Shared API request/response examples.
2. Error contract definitions.
3. Event payload contracts (webhooks and audit events).
